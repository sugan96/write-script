## Decision docs

Design and technology decisions live in `docs/`, one file per decision, numbered in order (`0001-screenplay-editor.md`, `0002-...`).

- Document the decision before developing the feature. Agree the decision with the user, write the doc, and commit it on the feature branch before any code commits.
- Read the related decision doc before changing code in that area.
- If your change reverses or alters a decision, update its doc first, in the same branch, before the code change.
- For a new decision, add the next numbered file.
